# Barcode Deck

An offline, open-source card wallet: scan or type a barcode once and
present it full-screen at checkout. No accounts, no cloud, no tracking.

- [Privacy policy](privacy-policy.html)
- Source code & issue tracker: [github.com/WebReflection/BarcodeDeck](https://github.com/WebReflection/BarcodeDeck)
